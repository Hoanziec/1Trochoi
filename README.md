# Đấu Trường Đường Cao Trên Lưới Ô Vuông (4 Vòng Chơi Đội Nhóm)

Phiên bản trò chơi theo đội nhóm với 4 vòng đa dạng, đồng hồ đếm ngược, thẻ gợi ý chiến thuật và tương tác chạm/nhấp trên cả máy tính và điện thoại.

## 4 Vòng Chơi
1. **Vòng 1: Bắt Đỉnh - Bắt Đáy** (10 điểm/câu, 30s)
2. **Vòng 2: Truy Tìm Lỗi Sai** (15 điểm/câu, 35s)
3. **Vòng 3: Chạm Vẽ Đỉnh Cao** (20 điểm/câu, 40s)
4. **Vòng 4: Thử Thách Nhân Đôi** (20 điểm/câu, 25s)

## Cách đưa lên GitHub Pages
1. Giải nén file `.zip` để lấy `index.html`.
2. Tạo repository trên GitHub và tải `index.html` lên thư mục gốc.
3. Vào **Settings -> Pages**, chọn nhánh chính (`main`) và thư mục `/ (root)`, bấm **Save**.
4. Mở đường link GitHub Pages trên máy tính hoặc điện thoại để tổ chức thi đua.
